# Eye Blink Detection

Counts blinks from the webcam. An eye that was detected inside a face and then disappears for a few frames counts as a blink (Haar cascades).

Part of a series of beginner-friendly OpenCV projects.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

Press `q` to quit any live window. Omit input arguments to use your webcam where supported.
